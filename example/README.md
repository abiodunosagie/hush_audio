# hush_audio example

A small Flutter app that plays the hush_audio engine: Solfeggio presets, steady, binaural and
pulsing tone modes, a beat-rate slider, seven noise colours and rain, with a ring that follows
the master gain through fades. State lives in a `SoundCubit` (`flutter_bloc`).

```bash
flutter run   # iOS, Android (API 26+) or macOS; needs rustup for the first build
```
